# Machine-Learning-Concepts

Small collection of hand-written MATLAB implementations of basic ML concepts — from course homework.

Requirements
- MATLAB 
- Basic plotting support

Quick start
1. Clone:
   git clone https://github.com/MoshenhavIsrael/Machine-Learning-Concepts.git
2. Run an example (MATLAB):
   - addpath(genpath(pwd)); then run e.g. Kmeans/Kmeans_alg or gmm_clustering/main_gmm

Contents
- pca/ — PCA example on faces images
- Kmeans/ — k-means implementation and test on mnist data. Graphs show the loss during optimization process.
- Logistic_regration/ — binary logistic regression and multinomial logistic regression on mnist data
- gmm_clustering/ — GMM example on random created data
